<h1>🎧 AudioBox — Interactive Sound Effects Player</h1>

<h3>AudioBox is a clean and interactive sound effects web application built using HTML, CSS, and JavaScript. Users can play unique sound clips, control volume via sliders, mute instantly, and enjoy smooth UI animations. Ideal for fun projects, beginner learning, or adding soundboards to websites.</h3>

<b>🚀 Features</b>

🔊 Play Audio on Click – Click any sound card to play/pause.

🎚️ Volume Control Slider – Adjust sound levels in real-time.

🔇 Single-Click Mute/Unmute – Tap the speaker icon to instantly mute.

⏯️ Dynamic Icons – Play icon switches to pause during playback.

🎨 Animated UI – Hover effects, shadows, clean layout.

🌌 Themed Background – Aesthetic gradient background image.

<b>🚀 TechStack</b>

| Technology       | Usage                                 |
| ---------------- | ------------------------------------- |
| **HTML5**        | Structure, audio elements             |
| **CSS3**         | Grid layout, animations, styling      |
| **JavaScript**   | Audio interactions and playback logic |
| **Font Awesome** | Icons (play, pause, volume)           |
| **Google Fonts** | Nova Square typography                |
